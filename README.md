# presence-report

Веб-приложение для анализа присутствия сотрудников по данным СКУД и плановым графикам. Flask + openpyxl.

## Возможности
- Загрузка Excel-выгрузки о присутствии сотрудников.
- Загрузка дополнительного отчета БЦ (СКУД здания) для сверки часов нахождения в офисе и интервалов прихода/ухода.
- Дашборд по департаментам.
- Дашборд по подразделениям.
- Анализ по сотрудникам с фильтрами (Департамент / Подразделение / Сотрудник).
- Динамика показателей по периодам.
- Экспорт результатов в Excel.
- Настройка видимых колонок и круговая диаграмма отклонений.
- Фильтры сохраняются при переключении между разделами.

## Запуск

1. Клонировать репозиторий:
git clone https://github.com/Alina-cyber1/presence-report.git
cd presence-report
2. Установить зависимости:
pip install -r requirements.txt
3. Справочник департаментов (опционально): файл `Справочник.xlsx` можно поместить в корень проекта, либо загрузить прямо через админ-панель (пункт 3 при загрузке файлов).
4. Запустить локально для теста: 
   `python app.py`
5. Для работы на сервере (продакшн): 
   `gunicorn -w 4 -b 127.0.0.1:5000 app:app`
6. Открыть в браузере `http://127.0.0.1:5000`.
   - `/` — дашборд для руководителей
   - `/admin` — загрузка файлов и публикация отчёта

## Демо (бесплатный план Render)
Приложение развёрнуто на Render:
- Дашборд для руководителей: https://presence-report.onrender.com
- Админ-панель (загрузка файлов): https://presence-report.onrender.com/admin

> **Примечание:** На бесплатном плане Render инстанс «засыпает» после 15 минут простоя. Первый запрос после сна может занять до 50 секунд. Данные в файловой системе не сохраняются между перезапусками: после «пробуждения» отчёт нужно загрузить заново через `/admin`.

## Структура

- `app.py` — приложение (Flask, всё в одном файле)
- `requirements.txt` — зависимости
- `Procfile` — команда запуска для Render
- `uploads/`, `exports/`, `config/` — создаются автоматически, в git не хранятся

## Разделы интерфейса

- **Дашборд по департаментам** — сводка по департаментам с фильтром.
- **Дашборд по подразделениям** — сводка по подразделениям с фильтром по департаменту и подразделению.
- **Анализ по сотрудникам** — детальная таблица по каждому сотруднику и по дням.
- **Динамика по периодам** — сравнение показателей месяц к месяцу.

На всех разделах доступен единый фильтр: **Департамент + Подразделение**
(на вкладке «Анализ по сотрудникам» дополнительно — **Сотрудник**).

## Экспорт в Excel

- Полная выгрузка по всем сотрудникам.
- Выгрузка по выбранному фильтру.
- Выгрузка дашборда (по департаментам или подразделениям).
- Выгрузка динамики по периодам.

## Данные
Приложение работает с внутренними данными о присутствии сотрудников. 
Файлы выгрузок и справочник подразделений в репозитории не хранятся и не публикуются. онфиденциальные данные (Excel-файлы, история) сохраняются только локально на сервере.
