# presence-report
Дашборд план/факт присутствия сотрудников: отчёт о посещении, опоздания, ранние уходы, переработки. Flask + openpyxl.


АНАЛИЗ ПРИСУТСТВИЯ СОТРУДНИКОВ
===============================

ЗАПУСК
------
1. Установите Python 3.10 или новее. При установке отметьте "Add Python to PATH".
2. Распакуйте папку attendance_prototype в любое место на компьютере.
3. Дважды щёлкните файл start.bat.
4. При первом запуске автоматически установятся зависимости (несколько секунд).
   При следующих запусках это будет пропущено — старт мгновенный.
5. Постоянное окно консоли не остаётся открытым: приложение запускается через pythonw.exe.
6. Браузер откроется автоматически на http://127.0.0.1:5000.
7. Загрузите Excel-файл отчёта и нажмите "Обработать".

СТРУКТУРА СТРАНИЦЫ: ДВЕ ВКЛАДКИ
---------------------------------
После загрузки файла под формой загрузки появляется меню из двух вкладок:

1. "Анализ по сотрудникам" — вся прежняя работа: таблица "Анализ данных" по
   сотрудникам, детализация по дням, фильтры, экспорт. Логика этой вкладки
   не менялась (допуски 10 и 5 минут сохраняются).
2. "Дашборд по подразделениям" — сводка только по подразделениям, без
   сотрудников. Работает по отдельной, более строгой логике (см. ниже).

Обе вкладки используют один и тот же загруженный файл — повторно загружать
его при переключении не нужно.

ВКЛАДКА "ДАШБОРД ПО ПОДРАЗДЕЛЕНИЯМ"
-------------------------------------
Показывает по каждому подразделению: сколько времени нужно было отработать
(план), сколько отработано фактически и в чём разница.

Принципы расчёта (одинаковы для всех сотрудников подразделения):
- Допусков нет. Любое отклонение считается с первой минуты. Правила
  "до 10 минут раньше — нормально" и "до 5 минут позже — нейтрально"
  в дашборде не применяются.
- План = РВ по рабочим дням (РВ больше нуля).
- Факт = время от прихода до ухода, но не раньше планового начала смены.
  Ранний приход в факт не входит и на разницу не влияет. Время после
  планового окончания смены в факт входит (поздний уход).
- Разница план/факт = факт минус план = поздние уходы минус опоздания
  минус ранние уходы.
- День, в котором РВ больше нуля, но нет ни интервала прихода/ухода, ни
  СКУД (СКУД = 0), считается потенциально удалённым. В план и факт он
  не включается, его РВ показывается в отдельной серой колонке.
- Дни с РВ = 0, в которые есть присутствие, считаются работой вне
  графика: часы выводятся отдельной колонкой и в план/разницу не входят.
- График "Свободный график" нормы не имеет: присутствие выводится в серую
  колонку "Свободный график" и не входит ни в план, ни в факт, ни в
  "Вне графика".
- У сотрудников без графика ("Увольнение сотрудника") нет времени начала
  смены, поэтому для них считаются только план и факт (РВ и СКУД). Их
  отклонение попадает в разницу, но не раскладывается на опоздания и уходы.
- Подразделения отсортированы по разнице план/факт: сверху те, где
  недоработка больше всего. Сотрудники без подразделения собраны в строку
  "Без подразделения".

Колонки таблицы:
  Подразделение; Сотрудники (для масштаба); План (РВ), ч; Факт, ч;
  Разница план/факт, ч (красная — недоработка, зелёная — переработка);
  Опоздания, ч; Ранние уходы, ч; Поздние уходы, ч; Вне графика, ч;
  серые справочные колонки: Ранний приход, ч; Потенциально удалённые, ч;
  Свободный график, ч. Внизу — строка ИТОГО. Часы показаны как ЧЧ:ММ.
  Подсказки с описанием каждой колонки появляются при наведении курсора
  на заголовок.

Кольцевой график "Структура отклонений" показывает долю четырёх
показателей: опоздания, ранние уходы, поздние уходы, вне графика.

Фильтр по подразделению: выберите подразделение и нажмите "Показать" —
таблица, карточки и график пересчитаются для него одного.

Выгрузка "Export Excel (Дашборд)": лист "Дашборд по подразделениям" (часы
в десятичном виде, строка ИТОГО) и лист "Описание значений". Если выбран
фильтр по подразделению, выгружается только оно.

СКОРОСТЬ ОБРАБОТКИ
-------------------
Файл примерно на 1000 сотрудников (31 день) обрабатывается за 2-5 секунд.
Во время обработки страница покажет сообщение "Файл обрабатывается".
Excel-файлы формируются только по нажатию кнопки экспорта.

ВКЛАДКА "АНАЛИЗ ПО СОТРУДНИКАМ"
---------------------------------
- Поля "Сотрудник" (автодополнение по ФИО) и "Подразделение". Кнопка
  "Показать" применяет фильтр, "Сбросить" возвращает всех.
- Цветовая подсветка строк в детализации по дням:
  * красный  — опоздание, ранний уход, аномально ранний приход, отсутствие
               интервала при рабочем дне, нераспознанный график;
  * жёлтый   — поздний уход свыше 5 минут или заметное отклонение
               продолжительности присутствия (СКУД) от нормы (РВ);
  * синий    — удалённая/гибридная работа без офисного присутствия,
               свободный график, посещение вне графика;
  * без подсветки — обычный рабочий день без отклонений.
- Подсказки по колонкам: у заголовков Рабочие дни, Удалённые дни, Опоздания,
  Ранние уходы, Аномально ранние приходы, Поздние уходы, СКУД выше РВ,
  СКУД ниже РВ и Статус формирования отчёта стоит значок (i). Наведите
  курсор на заголовок и подождите секунду — появится стандартная
  подсказка браузера с описанием. Работает без JavaScript.

ЭКСПОРТ ВКЛАДКИ "АНАЛИЗ ПО СОТРУДНИКАМ"
-----------------------------------------
1. "Export Excel (Полная выгрузка)" — всегда доступна, все сотрудники.
   Имя файла: "Полная выгрузка.xlsx".
2. "Export Excel по фильтру" — появляется при выбранном фильтре.
   - только подразделение -> имя файла = название подразделения;
   - выбран сотрудник -> "Моя выгрузка.xlsx".
Файл содержит три листа: "Анализ данных", "Дни" и "Описание значений"
(расшифровка девяти основных колонок).

ЛОГИКА ДЛЯ СОТРУДНИКОВ БЕЗ ГРАФИКА (УВОЛЬНЕНИЕ СОТРУДНИКА)
--------------------------------------------------------------
Если в исходном файле не заполнено поле "График работы", статус всегда
"Увольнение сотрудника" (обычно это принятые или уволенные в середине
месяца). Такие сотрудники участвуют в расчёте по упрощённым правилам:
  РВ > 0 и СКУД > 0  -> рабочий день. Сравниваются РВ и СКУД по
                        длительности, без проверки опозданий и уходов.
  РВ > 0 и СКУД = 0  -> удалённый день (потенциально). Идёт в "Удалённые
                        дни", проблемой не считается.
  РВ = 0             -> нерабочий день, ничего не засчитывается.

====================================================
ЗНАЧЕНИЯ КОЛОНОК: ЛИСТ "АНАЛИЗ ДАННЫХ" (И ТАБЛИЦА В БРАУЗЕРЕ)
====================================================

№
    Табельный или порядковый номер сотрудника из исходного файла.

Сотрудник
    Фамилия, имя и отчество. "(совм.)" в конце — отдельная запись
    совместителя, не объединяется с основной должностью.

Подразделение
    Подразделение сотрудника из исходного файла.

Формат работы
    "Работа в офисе", "Удаленная работа", "Гибридная работа" или "Не указан".

График
    Название графика из исходного файла. Пустое поле — "График не указан".

Рабочие дни
    Количество дней, где по графику было запланировано присутствие (РВ
    больше нуля). Включает удалённые и гибридные дни, а также рабочие дни
    сотрудников со статусом "Увольнение сотрудника".

Удалённые дни
    Сколько дней прошло без прихода в офис (нет интервала прихода/ухода и
    СКУД равен нулю). Не считается проблемой.

Опоздания
    Количество дней прихода позже начала смены. С первой минуты.

Ранние уходы
    Количество дней ухода раньше планового окончания. С первой минуты.

Аномально ранние приходы
    Количество дней прихода раньше плана более чем на 10 минут.

Поздние уходы
    Количество дней задержки после планового окончания более чем на 5 минут.

СКУД выше РВ
    Суммарные часы превышения фактического присутствия над нормой.

СКУД ниже РВ
    Суммарные часы недостачи фактического присутствия относительно нормы.

Статус формирования отчёта
    "Сформирован" — график распознан, показатели рассчитаны полностью.
    "Увольнение сотрудника" — график не указан, расчёт по упрощённым правилам.

====================================================
ЗНАЧЕНИЯ КОЛОНОК: ЛИСТ "ДНИ" (ДЕТАЛИЗАЦИЯ ПО ДНЯМ)
====================================================

№, Сотрудник, Подразделение, Формат работы
    Те же значения, что в "Анализ данных", повторены для каждого дня.

Дата
    Календарная дата в формате ДД.ММ.ГГГГ.

РВ
    Плановая норма присутствия на день (включает 1 час обеда).

СКУД
    Фактическая продолжительность присутствия по пропускной системе.

Интервал
    Время первого прихода и последнего ухода. Прочерк — нет полной отметки.

План
    Ожидаемый интервал присутствия (начало смены + РВ). "(+1 день)" — ночная
    смена. Для "Увольнение сотрудника" план не рассчитывается ("—").

Статусы
    Метки дня через точку с запятой: Опоздание, Ранний/Аномально ранний
    приход, Ранний/Поздний уход, Отклонение длительности СКУД от РВ,
    СКУД соответствует РВ, Удалённая работа, Гибрид/удалённая работа,
    Удалённая работа (потенциально), Свободное посещение/Подработка,
    Посещение вне графика/переработка, Нераспознанный график, Проблема:
    нет полного интервала.

ПРАВИЛА РАСЧЁТА КОРОТКО (ВКЛАДКА "АНАЛИЗ ПО СОТРУДНИКАМ")
-----------------------------------------------------------
- РВ больше 0 — день считается рабочим по графику.
- Один час обеда всегда включён в норму РВ.
- Плановое окончание смены = время начала графика + РВ.
- Опоздание и ранний уход считаются с первой минуты, без допуска.
- Ранний приход до 10 минут включительно — нейтрально, свыше — аномалия.
- Поздний уход до 5 минут включительно — нейтрально, свыше — фиксируется.
- Совместители с "(совм.)" в имени не объединяются с другими записями.

---------------------
